Avant de commencer

Faut-il un compte ?

Les fonctions audio locales ne nécessitent pas de compte. Un compte est utilisé pour les fonctions communautaires disponibles.

Comment utiliser MyVoice dans Discord ou un jeu ?

Un périphérique audio virtuel peut être nécessaire pour transmettre la sortie MyVoice. VB-CABLE est disponible sur le site de VB-Audio.

Mes enregistrements sont-ils publiés ?

Non. La transformation vocale fonctionne sur votre PC. Vos médias personnels ne sont pas publiés automatiquement.

Où signaler un problème ?

Rejoignez le serveur Discord My Projects et indiquez votre version de MyVoice ainsi que les étapes permettant de reproduire le problème.
